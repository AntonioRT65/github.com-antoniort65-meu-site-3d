# 🎲 Web 3D

Uma experiência 3D interativa desenvolvida para a web, criada com [Three.js / React Three Fiber / Spline].

---


## 📌 Sobre o Projeto

Este projeto foi desenvolvido como um experimento/demonstração de computação gráfica na web. O objetivo principal foi explorar  iluminação, animação 3D, interatividade com o usuário, físicas.

Ele faz parte do meu portfólio de projetos web e interativos.

---

## ✨ Funcionalidades

- 🔄 **Interação 3D:** Órbita de câmera, zoom e rotação controlados pelo usuário.
- 📱 **Responsivo:** Adaptado para diferentes tamanhos de tela.

---

## 🛠️ Tecnologias Utilizadas

- **Renderização 3D:** [Three.js / React Three Fiber / WebGL / Spline]
- **Front-end:** [HTML/CSS/JS ou React / Next.js / Vite]
